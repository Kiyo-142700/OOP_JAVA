# 🚀 Java Object-Oriented Programming (OOP) - CTU

Kho lưu trữ hành trình học tập và chinh phục môn **Lập trình Hướng đối tượng (OOP)** tại Trường Đại học Cần Thơ (CTU). Nơi đây tổng hợp toàn bộ mã nguồn bài tập thực hành trên lớp và các bài tập về nhà cá nhân.

---

## 📂 Cấu trúc Thư mục (Directory Structure)

Dự án được phân chia thành các module chính để dễ dàng quản lý và theo dõi tiến độ:

```text
.
├── ClassWork/          # 📝 Bài tập thực hành và hướng dẫn trên lớp
│   ├── TH_01/          # Buổi thực hành 01: Lớp, Đối tượng, Constructor
│   ├── TH_02/          # Buổi thực hành 02: Tính đóng gói, Kế thừa
│   ├── TH_03/          # Buổi thực hành 03: Đa hình, Lớp trừu tượng
│   └── ...
├── HomeWork/           # 💻 Bài tập về nhà, bài tự luyện & dự án nhỏ
│   ├── lcpc/           # Các bài toán thuật toán / luyện tập thêm
│   └── ...
├── .gitignore          # Cấu hình ẩn các file rác hệ thống (Eclipse/Bin)
└── README.md           # Tài liệu giới thiệu dự án

🛠️ Công nghệ & Công cụ Sử dụng
Ngôn ngữ: Java (JDK 21 LTS)

IDE: Eclipse / Visual Studio Code

Quản lý mã nguồn: Git & GitHub

🎯 Mục tiêu học tập
Nắm vững các nguyên lý cốt lõi của Lập trình Hướng đối tượng: Tính đóng gói (Encapsulation), Tính kế thừa (Inheritance), Tính đa hình (Polymorphism) và Tính trừu tượng (Abstraction).

Xây dựng thói quen viết code sạch (Clean Code), tổ chức Package chuẩn chỉnh theo mô hình hướng đối tượng thực tế.
